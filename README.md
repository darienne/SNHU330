# SNHU330
This repository showcases my coursework and final project for CS-330, where I explored the fundamentals of computational graphics using Modern OpenGL and GLSL. Over the seven-week course, I progressed from foundational concepts to building a fully functional 3D scene rendered entirely through code and mathematical transformations in C++, using Visual Studio 2022.

For my final project, I designed a 3D scene featuring a computer with a coffee cup on a tabletop with a backdrop. I implemented dynamic lighting, shadows, camera movement, and three distinct textures. One of my proudest achievements was adding reflective effects—where textures bounce off the moon’s surface depending on the camera angle—even though reflections weren’t part of the original rubric. This extra feature stemmed from a misinterpretation of the assignment, but it led to valuable learning and creative problem-solving.

I focused on selecting objects that balanced visual appeal and complexity, while structuring my code modularly through functions. My use of shaders, textures, and lighting was guided by a goal of producing a polished, immersive 3D experience.

Design Skills Acquired

Modular code architecture for maintainability

Integration of textures and shaders for realism

Spatial arrangement of 3D objects for coherent scene composition

Design Process I selected and positioned objects, implemented camera and navigation controls, and iteratively refined lighting and shader effects. Custom functions supported a clean, reusable structure.

Future Design Applications: The modular design tactics I used will support future projects by improving scalability and user experience. Prioritizing visual and interactive elements helps create more engaging software.
Development Approach I built the scene incrementally, combining rendering, navigation, and control logic to ensure cohesive functionality.

Strategies Used

Custom functions for rendering and camera control

Iterative tuning of lighting, textures, and shaders

Role of Iteration: Iteration was key to refining visual quality and interactivity. I repeatedly adjusted parameters to achieve the desired aesthetic and responsiveness.

Evolution of My Approach My development evolved from isolated component testing to full integration, demonstrating my ability to synthesize diverse elements into a unified application.
